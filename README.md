# 週末影展小幫手（網頁課程作業 HW02）

本專案為網頁課程作業（HW02）之實作成果，提供一個簡潔、無廣告、專注於迷你足球影展時程規劃與想看片單收藏的純前端 Web 應用服務。

---

## 專案用途說明

- **課程專題企劃**：協助使用者模擬策劃一個小型週末足球主題影展，自行安排放映時間表與場地休息換場時段。
- **重要聲明**：本服務僅為課堂技術習作，**非實際商業售票活動**，未對外販售票券或提供串流放映服務。
- **個資保護原則**：本專案不需帳號密碼、不要求也不記錄任何姓名、學號、電話、電子郵件等個人隱私資訊。

---

## 主要功能特色

1. **精選雙部足球主題片單**：
   - 包含《我愛貝克漢》（*Bend It Like Beckham*）與《足球尤物》（*She's the Man*）。
   - 附有各電影之官方頁面連結（Searchlight Pictures 與 Paramount Pictures）。
   - 僅提供圍繞足球、女孩踢球突破框架與家庭期待之簡要主題介紹，不臆測未知年份與片長。
2. **片單收藏功能**：
   - 可一鍵將電影加入或移出個人收藏。
   - 正確計算並即時顯示當前收藏數（0 ~ 2 部）。
   - 採用瀏覽器 `localStorage` 永久保存，重新整理或重開瀏覽器後狀態不遺失。
3. **影展場次排定表單**：
   - 支援選擇放映電影、設定開始時間（HH:mm）。
   - 可自訂規劃放映長度（分鐘）與中場休息時間（分鐘），並於介面明確提醒此為活動規劃時長而非官方公布片長。
   - 嚴謹的輸入驗證與無障礙設計：
     - 空白欄位防呆。
     - 正整數驗證（放映長度須為 > 0 之正整數；休息時間須為 >= 0 之整數）。
     - 時間格式檢查（24 小時制 HH:mm）。
     - 當日 24:00 邊界檢查：超過當日 24:00 拒絕加入並給予提示。
     - 時段重疊衝突偵測：若與已排定場次時間相交，明確指出重疊場次名稱與衝突時段並拒絕加入。
     - 提供清楚的行內錯誤提示（Inline Errors）與 `aria-live` 狀態朗讀支援。
4. **場次列表管理與排序**：
   - 依場次開始時間自動由早至晚排序。
   - 支援單一場次個別刪除功能。
   - 所有場次資料同步儲存於 `localStorage`，重新整理網頁時完整保留。
5. **匯出 UTF-8 CSV 場次表**：
   - 一鍵將已排定的場次表下載為 CSV 試算表。
   - 檔案開頭加入 UTF-8 BOM（`\uFEFF`），確保微軟 Excel 或各試算表軟體開啟繁體中文時均能正常顯示而不亂碼。
6. **綠色系學生手作風格視覺**：
   - 採用米白色背景、深綠色主調與少量溫暖橘色重點標示。
   - 使用系統原生字體（System Font Stack），不使用多餘漸層、無干擾性動畫、無外部圖片載入，行動裝置直向操作流暢友善。
   - 不串接任何外部第三方 API、不使用付費金鑰服務、不捏造虛假人工智慧推薦。

---

## 技術實作與無 API 設計說明

- **技術架構**：以 React 19、TypeScript 與 Vite 為基礎，搭配 Tailwind CSS 原生純淨排版。
- **純前端運作（無串接外部 API）**：
  - 本服務為純靜態單頁應用（SPA），**不呼叫任何外部後端伺服器或第三方 API**。
  - 無需任何 API 金鑰（API Key）、不依賴付費雲端服務。
  - 不使用任何人工智慧模型或自動生成推薦，所有功能均以原生 TypeScript 邏輯於客戶端即時運算（包括時間重疊判斷、正整數與邊界防呆、CSV 字串編碼產生等）。
- **資料儲存**：全數使用 HTML5 Web Storage API（`window.localStorage`），資料 100% 保存在使用者目前操作的瀏覽器端。

## 本地開發與建置指引

本專案使用 **React 19 + TypeScript + Vite + Tailwind CSS** 建置。

### 1. 安裝套件依賴

請於專案根目錄執行以下指令安裝所需套件：

```bash
npm install
```

### 2. 啟動本機開發伺服器

執行開發指令，啟動本地預覽服務：

```bash
npm run dev
```

啟動後，依終端機提示於瀏覽器開啟 `http://localhost:3000`（或終端機顯示之連接埠）即可瀏覽與測試操作。

### 3. 建置生產環境檔案

如需打包輸出部署檔案，請執行：

```bash
npm run build
```

打包完成後之靜態網頁檔案將產出於 `dist/` 資料夾中。

## 本地資料儲存說明（LocalStorage）

本應用程式採純前端無伺服器架構：
- 收藏清單儲存於瀏覽器鍵值：`weekend_filmfest_favorites_hw02`
- 場次時程儲存於瀏覽器鍵值：`weekend_filmfest_sessions_hw02`
- 所有資料僅留存於您的個人瀏覽器中，不會上傳至任何伺服器或第三方資料庫，保護使用者隱私與操作自主性。

## 部署至 Vercel 步驟指引

本專案已完成標準 Vite 建置設定，可免費部署至 Vercel 平台：

1. **將專案推送至 GitHub**：
   - 於 GitHub 建立一個新的儲存庫（Repository），並將專案程式碼 push 至該儲存庫。
2. **登入 Vercel**：
   - 前往 [https://vercel.com](https://vercel.com) 並使用 GitHub 帳號登入。
3. **匯入專案（Import Project）**：
   - 點擊「Add New...」按鈕，選擇「Project」。
   - 在專案清單中選取剛才建立的 GitHub 儲存庫並點擊「Import」。
4. **確認專案設定**：
   - **Framework Preset**：系統通常會自動偵測為 `Vite`。
   - **Build Command**：`npm run build`
   - **Output Directory**：`dist`
   - **Install Command**：`npm install`
5. **點擊「Deploy」發布**：
   - 點擊 Deploy 按鈕，Vercel 將自動完成建置並產生公開訪問網址（例如 `https://your-project-name.vercel.app`）。
   - 部署完成後即可隨時在任何裝置（包含智慧型手機）上進行操作與展示。
